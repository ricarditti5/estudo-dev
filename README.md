# 🚀 Estudo Dev - Repositório Geral

Este repositório centraliza meus projetos práticos, exercícios e anotações relacionados ao aprendizado contínuo em desenvolvimento de software e tecnologias web.

## 📁 Estrutura do Repositório

O repositório está dividido por tecnologias e áreas de estudo. Cada diretório contém seus próprios recursos, projetos e documentações específicas.

### ⚛️ [React](./React/README-REACT.md)
Área dedicada ao estudo de **React** e seu ecossistema (juntamente com Vite e JavaScript moderno).
- Contém múltiplos projetos hands-on focados nos fundamentos da biblioteca: componentes, propriedades (props), eventos, listas, entre outros.
- 📖 **[Acesse a documentação detalhada do módulo React](./React/README-REACT.md)** para ver a lista completa de projetos e seus respectivos conceitos abordados.

### 🐹 [Go](./Go/)
Área dedicada aos estudos práticos e desenvolvimento em **Go (Golang)**.
- Atualmente conta com dezenas de exercícios focados na sintaxe, estrutura e funcionamento nativo da linguagem (do `exercicio1` ao `exercicio18`, além de scripts independentes como `hello.go`).

### 🐳 [Docker](./Docker/README-DOCKER.md)
Anotações e primeiros passos visando a conteinerização de aplicações com **Docker**.
- Práticas que englobam a clonagem, modificação de imagens conteinerizadas e submissão (push) para o Docker Hub.
- 📖 **[Veja as anotações do Docker](./Docker/README-DOCKER.md)** para referências e links úteis.

## 🛠️ Como Executar

O modo de execução ou visualização varia de acordo com o projeto ou tecnologia analisada. O ideal é navegar até a pasta desejada e conferir a documentação local (geralmente nos arquivos `Doc.md` ou README da linguagem).

**➡️ Exemplo prático (Projetos React):**
```bash
cd React/Components-1
npm install
npm run dev
```

**➡️ Exemplo prático (Scripts em Go):**
```bash
cd Go
go run hello.go
```
